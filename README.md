# Latch

> Latch is a webhook infrastructure concept focused on persistent endpoints, delivery inspection, debugging, and one-click replay.

Built for the Acdyon Technologies Frontend Challenge (Part 2).

### Features

- Persistent webhook endpoints
- Delivery inspection
- Payload/header visibility
- Replay workflow
- Responsive landing page
- Dark/light theme

### Tech Stack

- Vite 6
- React 19
- CSS custom properties (no UI framework)
- IBM Plex Mono + Inter (Google Fonts)

### Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

### Production Build

```bash
npm run build
npm run preview
```

## Deploy

**Vercel:** Framework Vite, build command `npm run build`, output directory `dist`.
